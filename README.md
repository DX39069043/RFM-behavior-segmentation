# 用户价值与购买潜力分层 · UserValue&Potential

## 项目目标

基于 2019 年 10 月的用户行为日志建立可解释分层，识别两类可运营人群：

- **高潜力首购用户**：建模月未购、但具有高探索度与高决策摩擦的用户；
- **高价值高摩擦用户**：已购用户中价值指数位于前 25%、且在观察月完全沉默（无任何行为）的高价值买家——跨月完全沉默即流失判定。

使用独立月份数据开展时间外验证，检验标签对后续购买行为的区分能力。该验证为观察性预测验证，**不等同于营销 A/B 实验或因果增量**。

## 数据与口径

数据来自 Kaggle：[e-Commerce Behavior Data from Multi Category Store](https://www.kaggle.com/datasets/mkechinov/ecommerce-behavior-data-from-multi-category-store)。本项目统一使用 **7 个月用户面板**（按 user_id 哈希抽样 5%，约 78 万用户 / 2060 万条事件，`data/panel_7months.parquet`）：**10 月事件（约 212 万条）用于建模/EDA，11 月事件（约 339 万条）用于正式验证**，全部分析共用同一数据源。

- 分析粒度：用户；有效停留时长先按 `user_id + user_session` 排序计算，相邻事件间隔小于 30 分钟才计入；
- 探索度 `E_Score`：浏览页数、有效停留时长、会话数经 `log1p + Z-score` 后等权平均；
- 决策摩擦 `Friction`：加购但未购买的去重商品数（`max(去重加购商品数 − 去重购买商品数, 0)`，log1p 变换），与浏览页数无关；它反映“购物车意图未兑现”，不把它解释为真实支付失败；
- 高潜力首购：只在建模月未购用户内部，采用两成分 GMM 的后验概率交点同时划分 E_Score 和 log(Friction)（未购用户中 92% 无加购，log(Friction) 阈值自然退化为“有加购即高摩擦”）；
- 高价值：只在已购用户内部，根据 `log(消费额)+log(购买频次)-log(最近购买天数)` 的上四分位划分，再按 E_Score 细分为深度互动/直购；
- 高价值高摩擦（流失）：基期高价值买家在观察月完全无任何事件（view/cart/purchase 都没有），由 `flag_buyer_silence` 标记。

## 方法改进

本版取消“将 8 个 K-Means 簇强制补齐到传统 RFM 八象限”的做法：当零购买用户占多数时，该做法会产生大量同向簇并失去标签含义。改用“先按是否购买分流、再按业务可解释指标分层”，阈值只在基期月拟合，避免验证期信息泄露。

## 验证

正式验证为**滚动时间外验证**（7 个月面板逐对检验，6 组实验一 + 5 组实验二，样本量与跨月重复均优于单一月份对）：

1. **实验一（未购臂）**：高潜力首购用户 vs 普通浏览用户的次月购买率。2019-10→11 组：5,408 vs 12.85 万用户，购买率 **13.30% vs 5.41%**（购买率差 +7.88pp，p=2.2e-131）；6/6 个月对显著，购买率差 +4.5~+9.3pp 跨月稳定；
2. **实验二（已购臂·跨月沉默）**：基期高价值买家在观察月完全沉默后，其验证月购买率与活跃高价值对照组的比较（3 月组滚动验证，避免“沉默月=结果月”循环）；5/5 个月组极显著，购买率差 −19.9~−31.8pp（p<1e-68）；
3. **两臂 LR 基准**：逻辑回归（5 折 OOF）证明概率分排序优于规则分层（未购臂 2019-10→11 组 AUC 0.528→0.673，Top-k 首购率 13.30%→16.31%）；
4. 导出可供后续触达实验使用的名单（`tracked_users_list_Nov.csv`，6,792 人 = 5,408 高潜力首购 + 1,384 沉默高价值）。真正的营销增量需通过随机 A/B 实验确认。

## 队列迁移分析（标签稳定性）

固定 2019-10 为基期，用**冻结的基期阈值**逐月重算同一批用户的标签，回答“高价值直购 / 深度互动 / 常规已购 等标签是保持还是转化”（阈值冻结保证跨月可比，不受每月重新拟合的阈值漂移污染）。产出 1 张 CSV（`run_cohort.py`，需 7 个月面板）：

- `cohort_frozen_labels.csv`：基期标签 × 月份 × 冻结标签占比（标签保持 / 转化；"无任何活动" = 当月完全无行为）。

核心结论：已购三标签的月度保持率较低（次月 12%~17%，6 个月后降至 2%~6%），标签是“月度快照”、需按月刷新；高价值深度互动粘性最强（次月购买占比 45.9%、无任何活动占比最低 24%），常规已购流失风险最高（40.5% 次月无任何活动）。

## 运行

```bash
pip install -r requirements.txt
jupyter notebook main.ipynb
```

按 Notebook 顺序运行即可重新生成 `tracked_users_list_Nov.csv`（需 7 个月面板 `data/panel_7months.parquet`，可运行 `python sample_user_cohort.py` 从按月 csv.gz 重建）。滚动验证 / 队列迁移结果默认读取现成 CSV（`run_rolling.py`、`run_cohort.py` 可重算）。

## 简历表述（运行后填写实际指标）

> 基于 78 万用户、7 个月电商行为日志构建用户价值与首购潜力分层，按会话级浏览深度、停留时长和“加购未买”摩擦识别高潜力未购用户；以次月独立数据完成时间外验证，量化分群的购买率差及 95% 置信区间，并输出可用于后续随机 A/B 测试的运营触达名单。

## 目录

- `main.ipynb`：可复现分析、时间外验证和名单导出（EDA → 分层 → 滚动验证（正式）→ 汇总 → LR 基准 → 概率分圈人 → 名单 → 队列迁移分析）；
- `analysis.py`：特征构建、GMM 阈值、分层（含冻结阈值）、跨月沉默、检验、LR 基准、打分、滚动验证与队列迁移；
- `config.py`：集中配置（路径、月份、随机种子、会话阈值）；
- `run_rolling.py`：滚动验证入口（需 7 个月面板，生成两张结果 CSV）；
- `run_cohort.py`：队列迁移分析入口（需 7 个月面板，生成冻结标签 CSV）；
- `sample_user_cohort.py`：按用户哈希抽样生成 7 个月面板；
- `tests/`：单元测试（18 个用例）：`python -m unittest discover -s tests`；
- `data/panel_7months.parquet`：7 个月用户面板（全部分析的数据源）；
- `tracked_users_list_Nov.csv`：Notebook 运行后生成的候选用户名单。
