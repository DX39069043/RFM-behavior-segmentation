# 用户价值与购买潜力分层 · UserValue&Potential

## 项目目标

基于 2019 年 10 月的用户行为日志建立可解释分层，识别两类可运营人群：

- **高潜力首购用户**：建模月未购、但具有高探索度与高决策摩擦的用户；
- **高价值高摩擦用户**：已购用户中价值指数位于前 25%、且加购未买（购物车意图未兑现）较多的用户。

使用独立的 11 月数据开展时间外验证，检验标签对后续购买行为的区分能力。该验证为观察性预测验证，**不等同于营销 A/B 实验或因果增量**。

## 数据与口径

数据来自 Kaggle：[e-Commerce Behavior Data from Multi Category Store](https://www.kaggle.com/datasets/mkechinov/ecommerce-behavior-data-from-multi-category-store)。本项目样本包含约 56.8 万条事件日志：10 月 30.9 万条用于建模，11 月 25.9 万条用于验证。

- 分析粒度：用户；有效停留时长先按 `user_id + user_session` 排序计算，相邻事件间隔小于 30 分钟才计入；
- 探索度 `E_Score`：浏览页数、有效停留时长、会话数经 `log1p + Z-score` 后等权平均；
- 决策摩擦 `Friction`：加购但未购买的去重商品数（`max(去重加购商品数 − 去重购买商品数, 0)`，log1p 变换），与浏览页数无关；它反映“购物车意图未兑现”，不把它解释为真实支付失败；
- 高潜力首购：只在建模月未购用户内部，采用两成分 GMM 的后验概率交点同时划分 E_Score 和 log(Friction)（未购用户中 92% 无加购，log(Friction) 阈值自然退化为“有加购即高摩擦”）；
- 高价值：只在已购用户内部，根据 `log(消费额)+log(购买频次)-log(最近购买天数)` 的上四分位划分。

## 方法改进

本版取消“将 8 个 K-Means 簇强制补齐到传统 RFM 八象限”的做法：当零购买用户占多数时，该做法会产生大量同向簇并失去标签含义。改用“先按是否购买分流、再按业务可解释指标分层”，阈值只在 10 月拟合，避免 11 月信息泄露。

验证包含：

1. 高潜力首购用户与其余未购用户的 11 月购买率比较（卡方检验、风险差及 95% CI）；
2. 高价值高摩擦用户与**同为高价值但低摩擦**的 VIP 对照组的 11 月购买率比较（加购未买口径下差异不显著，p=0.342）；
3. 导出可供后续触达实验使用的名单。真正的营销增量需通过随机 A/B 实验确认。

## 运行

```bash
pip install -r requirements.txt
jupyter notebook main.ipynb
```

按 Notebook 顺序运行即可重新生成 `tracked_users_list_Nov.csv`。原始数据文件需与 Notebook 位于同一目录。

## 简历表述（运行后填写实际指标）

> 基于 56.8 万条电商行为日志构建用户价值与首购潜力分层，按会话级浏览深度、停留时长和“加购未买”摩擦识别高潜力未购用户；以次月独立数据完成时间外验证，量化分群的购买率风险差及 95% 置信区间，并输出可用于后续随机 A/B 测试的运营触达名单。
